I'm a **freelance Full-Stack & Front-End Developer (ZZP)** based in **Eindhoven, the Netherlands**. I design and build complex, production-ready web applications, from pixel-perfect interfaces to scalable APIs and database architecture.

My strength is **turning UX principles into solid technical solutions**. I care about how a product *feels* to the end user, and I can engineer the system behind it so that it performs, scales and stays maintainable.

## 🌟 Featured Project

### 🫒 [Zaytoon](https://zaytoon.site): SaaS E-Commerce & POS Platform for Restaurants

> A scalable, multi-tenant SaaS platform that gives restaurants their own digital storefront, QR menu, ordering system and admin dashboard, all from one codebase.

**Highlights**

- ⚡ **Real-time order flows:** orders move from the customer to the restaurant dashboard with live status updates.
- 💬 **Hybrid WhatsApp checkout:** combines structured online ordering with the communication channel restaurants already use.
- 🏢 **Multi-tenant architecture:** each restaurant gets its own isolated dashboard, branding and public menu page.
- 🗄️ **Complex relational database design:** tenants, menus, categories, items, orders, subscriptions and pricing logic.
- 🌐 **Bilingual & RTL-ready:** full Arabic/English support with a live language toggle.
- 🧰 **Owner tooling:** drag-and-drop menu ordering, bulk price adjustments, discounts, media and branding management.
- 💳 **SaaS subscription model:** plan tiers and subscription lifecycle handling.
- 🌍 **Resilient delivery:** built to perform in regions with restricted CDN access.
